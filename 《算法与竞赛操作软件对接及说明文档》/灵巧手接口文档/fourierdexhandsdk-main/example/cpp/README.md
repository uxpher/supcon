# DexHand SDK Demo

## Usage

### Dependencies

- Linux system (currently only Linux is supported)  
- C++17 compiler（GCC or Clang）  
- libFourierDexHand.so dynamic library file  

### Build the Project

```bash
mkdir build && cd build
cmake ..
make
```

### Run the Program

```bash
./bin/fourier_dexhand_sdk_demo
```

## Notes

- Ensure that the device is properly connected and the network configuration is correct.
