# DexHand SDK Demo

## Usage

### Dependencies

- Linux system (currently only Linux is supported)  
- Python 3.10 (recommended)
- pybind11  
- dexhandpy  

### Python Library

Python Library Installation:  
```bash
# pybind11
pip install pybind11
# release
pip install dexhandpy
```

### Run the Program

```bash
cd example/python/
python3 fourier_dexhand_sdk_demo.py
```

## Notes

- Ensure that the device is properly connected and the network configuration is correct.
